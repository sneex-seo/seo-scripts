# Розрізати CSV на частини

`cut_csv.py` ділить великий CSV на кілька файлів. Корисно, коли сервіс приймає файли з обмеженням за кількістю рядків.

## Як запустити

```bash
pip install pandas
python cut_csv.py
```

Скрипт запитає:

1. Повний шлях до файлу.
2. Мінімальну і максимальну кількість рядків в одній частині. Розмір кожної частини обирається випадково в цьому діапазоні. Щоб частини були однакові, введіть те саме число двічі.

Частини зберігаються поруч з оригіналом: `файл_1.csv`, `файл_2.csv` і т.д.
