# Пошук піддоменів

`subdomains.py` перебирає піддомени зі словника для кожного домену і зберігає ті, що відповідають, разом з їхніми IP. Так можна знайти забуті тестові версії сайту, дзеркала і дублі, які потрапляють в індекс.

## Як запустити

1. Впишіть домени в `domains.txt`, по одному в рядку, і видаліть рядок-підказку.
2. Словник піддоменів лежить у `subdomains.txt`, це близько 10 тис. варіантів. Для швидкої перевірки залиште тільки популярні.
3. Запустіть:

```bash
pip install requests
python subdomains.py
```

Знайдені піддомени дописуються в `Subdomain+IP.csv`. Перевірка повного словника займає довго, бо запити йдуть по черзі.
