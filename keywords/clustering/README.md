# Базова кластеризація ключів

`Clusterisationtool.py` групує ключові слова за схожістю слів: стемінг, векторизація TF-IDF і кластеризація Affinity Propagation. Кількість кластерів алгоритм визначає сам.

## Як запустити

1. Впишіть ключі в `keywords.txt`, по одному в рядку.
2. Запустіть:

```bash
pip install pandas numpy nltk "scikit-learn<1.2"
python Clusterisationtool.py
```

Результат: `result.csv`, де колонка `pred` - номер кластера.

## Обмеження

- Стемер налаштований на англійську (`SnowballStemmer("english")`). Для інших мов змініть мову стемера.
- Скрипт використовує `get_feature_names()`, якого немає в scikit-learn 1.2+. На новій версії замініть виклик на `get_feature_names_out()`.
- Кластеризація лексична: «купити диван» і «диван ціна» потраплять разом, а синоніми без спільних слів - ні. Для кластеризації за видачею Google потрібен інший підхід.
