# Підказки Google

`suggest.py` збирає пошукові підказки Google для кожного ключа зі списку і відкидає ті, що містять стоп-слова.

## Як запустити

1. Впишіть ключі в `keysforparsing.txt`, по одному в рядку.
2. За потреби відредагуйте список `stopwords` у функції `clean_stop_words`.
3. Регіон і мова підказок задаються в рядку `params`: зараз це `gl=ua&hl=ru`.
4. Запустіть:

```bash
python suggest.py
```

Результат дописується в `suggest.csv`. Між запитами пауза 1,5 секунди, щоб Google не обмежив доступ.

Сторонні бібліотеки не потрібні, лише стандартний Python.
