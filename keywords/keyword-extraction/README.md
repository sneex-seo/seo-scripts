# Ключові слова з тексту

`tfidf.py` витягує з тексту найважливіші слова за алгоритмом [YAKE](https://github.com/LIAAD/yake). Попри назву файлу, це не TF-IDF: YAKE оцінює слова за статистикою одного документа, без корпусу.

## Як запустити

1. Вставте текст у `text.txt`.
2. У коді за потреби змініть:
   - `language` - код мови тексту (зараз `ru`);
   - `max_ngram_size` - довжина фраз: 1 для окремих слів, 2 для біграм і т.д.;
   - `numOfKeywords` - скільки ключів вивести (зараз 20).
3. Запустіть:

```bash
pip install yake
python tfidf.py
```

Результат дописується в `result.csv`: слово і його оцінка. Чим менша оцінка, тим важливіше слово.
